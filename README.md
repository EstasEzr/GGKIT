# Единая информационная система ГГКЭИТ

Портал колледжа на ASP.NET Core 10, Vue 3 и SQLite. Русскоязычный интерфейс, расписание в недельной сетке на компьютере и в виде списка выбранного дня на телефоне. Время звонков и даты отображаются по Минску.

## Локальный запуск

Откройте PowerShell в папке проекта. Нужен .NET SDK 10. При первом восстановлении пакетов нужен NuGet либо локальный кэш. Vue уже включён в проект.

```powershell
dotnet restore
$env:ASPNETCORE_ENVIRONMENT = 'Development'
$env:BootstrapPassword = Read-Host 'Пароль первого администратора'
dotnet run --no-launch-profile --urls http://localhost:5190
```

Откройте [портал](http://localhost:5190) и войдите с логином `admin` и выбранным паролем. Переменная `BootstrapPassword` используется только для пустой БД. После первого запуска её можно удалить из среды.

Администратор создаёт сотрудников в разделе «Сотрудники». Для назначения и переназначения кураторов в разделе «Учебные группы» нужна роль «Администрация». Настроить календарь недель могут администрация и заместитель с правом «Календарь недель». Роли можно совмещать. После изменения собственной учётной записи войдите повторно.

## Группы и учащиеся

При загрузке базового XLSX новые группы создаются без куратора. Начальное значение года набора берётся из года загрузки файла. Куратор может закрепить за собой свободную группу и затем добавить учащихся. Администрация может назначить или сменить куратора. У группы один куратор, у куратора может быть несколько групп. При совпадении номера группа сохраняется после отдельного подтверждения. Учащийся входит по ФИО и номеру зачётной книжки. Тёзок различают по паролям, поэтому у учащихся с одинаковыми ФИО пароли должны отличаться. Куратор меняет пароль в карточке. Деактивация прекращает доступ, включая действующие сеансы.

## Импорт и публикация

1. В разделе «Публикация расписания» можно указать дату известной недели и её тип. Система чередует типы по понедельникам. Если календарь ещё не задан, неделя загрузки первого опубликованного расписания с чередованием считается неделей «над чертой».
2. В разделе «Публикация расписания» загрузите XLSX с листами «ПТО» и «ССО». Для DOCX с заменами дата берётся из заголовка. Повторная загрузка того же XLSX открывает существующий пакет.
3. В предпросмотре проверьте записи и сопоставьте неоднозначные группы. DOCX с заменами использует существующие группы, поскольку в нём не указан уровень ПТО или ССО. Для XLSX показана исходная ячейка, для DOCX — строка и позиция. Кабинеты сохраняются как текст. Спорные сокращения и варианты занятий проверяются по исходнику. В пределах группы и дня первое вхождение повторяющегося номера урока относится к неделе «над чертой», последующие — к неделе «под чертой». Строки с нераспознанными номерами пропускаются и перечисляются в предупреждениях предпросмотра.
4. Подтвердите практику на весь день через редактирование записи. Расхождение типа недели в DOCX с календарём показано в предпросмотре. Замены применяются на указанную в файле дату.
5. Откройте список изменений и опубликуйте пакет. Опубликованное базовое расписание применяется ко всем датам до публикации новой версии. Для каждой даты публикуется один пакет замен. Ручная правка начинается с копии опубликованного пакета этой даты, если он существует. Новый импорт на ту же дату заменяет весь предыдущий пакет после публикации. Удаление строки из ручного черновика и его публикация или снятие всего пакета возвращают применимое базовое занятие.

В комплекте есть звонки для уроков 1–13. Время 12-го — 18:20–19:05, 13-го — 19:15–20:00.

## Эксплуатация

- Для запуска вне локальной разработки настройте HTTPS-сертификат и HTTPS-привязку Kestrel. Укажите пути и секреты сертификата через конфигурацию ASP.NET Core. Для выпуска выполните `dotnet publish -c Release`, затем запускайте `dotnet GGKEIT.dll` из каталога публикации.
- Параметр `DataDirectory` задаёт каталог базы и ключей сеансов. Ограничьте права на каталог учётной записью службы. При запуске применяются SQL-миграции из `Migrations`.
- Вложения материалов и новостей хранятся в SQLite. Для согласованной резервной копии БД вместе с файлами выполните `dotnet GGKEIT.dll backup D:/backups/college-2026-11-12.sqlite` с тем же `DataDirectory`. Для восстановления остановите портал, сохраните копию текущей БД и замените её резервной. Храните ключи сеансов отдельно с ограниченным доступом.
- Журнал операций хранится в таблице `audit`. В неё записываются автор, время, тип операции и идентификатор записи для публикаций, календаря и изменений ролей.
- Лимит вложения или файла импорта — 8 МБ. Материалы и вложения выдаются через API с проверкой аудитории и прав на запись.

## Зависимости интерфейса

В `wwwroot/vendor/vue.js` находится Vue 3.5.13 с лицензией MIT. Команды `npm install` и `npm run vendor` восстанавливают этот файл при необходимости. Логотип и иллюстрации в шапке и боковой панели берутся из предоставленного макета.
